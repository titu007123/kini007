KINI007 Seller Management add-on (add-only)

1. Upload kini007-seller-management.js to the repository root (same folder as admin.html).
2. In admin.html, add this one line AFTER the existing admin.js script and AFTER the Supabase SDK/config scripts:
   <script src="kini007-seller-management.js"></script>
3. Do not replace admin.html or admin.js. Do not remove existing analytics/performance/quality script lines.
4. Commit the new JS file and the one-line admin.html edit.

The add-on creates a Seller Management navigation item and section after the existing Admin Panel loads.
It checks the signed-in session and active admin_users row before reading seller_profiles.
It uses the private seller-identity-documents bucket and creates 60-second signed URLs.
It expects seller_profiles to contain identity_document_path. If your actual column has a different name, the page will show a database error; do not change database columns without checking first.
Never put a Supabase service_role/secret key in browser code.
