KINI007 Seller Dashboard + Product Upload (additive files)

FILES
- seller-dashboard.html: standalone seller dashboard page
- seller-dashboard.css: dashboard styling
- seller-dashboard.js: authenticated seller product upload/list/edit/hide/delete
- seller-marketplace-setup.sql: additive database and storage setup

INSTALL ORDER
1. Confirm a fresh products CSV backup is safely saved.
2. In Supabase SQL Editor, paste seller-marketplace-setup.sql and Run it. It adds seller_id and seller-owned RLS policies plus a public product-image bucket. It does not delete existing products.
3. In GitHub repository root, Add file -> Upload files. Upload seller-dashboard.html, seller-dashboard.css, seller-dashboard.js.
4. Commit changes.
5. Open the seller portal at https://titu007123.github.io/kini007/seller.html and log in with the seller account.
6. After login, open https://titu007123.github.io/kini007/seller-dashboard.html in the same browser. The dashboard uses the same Supabase Auth session.

IMPORTANT
- Do not replace seller.html, seller.js, admin.html, admin.js, app.js, or supabase-config.js.
- Do not upload service_role/secret keys.
- Seller listings publish as active immediately, matching the chosen no-approval workflow.
- Seller can only access rows where seller_id equals their own authenticated user ID, enforced by RLS.
- Public storefront currently displays products from products table. This dashboard creates product listings; a full customer cart/checkout/order flow is a later separate phase.
- Product images are public because they appear on the public storefront. Identity documents remain in their separate private bucket.
- Existing affiliate/admin products keep seller_id NULL and are not modified by this setup.
