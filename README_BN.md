# Kinioo7 — বিনামূল্যের Android-ইনস্টলযোগ্য ওয়েব অ্যাপ

এটি একটি PWA (Progressive Web App) প্রোটোটাইপ। Android Chrome থেকে ওয়েবসাইট খুলে **Install app / Add to Home screen** করলে অ্যাপের মতো ব্যবহার করা যাবে।

## ফাইলগুলো
- `index.html` — অ্যাপের কাঠামো
- `style.css` — ডিজাইন
- `app.js` — নমুনা কনটেন্ট, সার্চ, ক্যাটাগরি ও ভাষা বোতাম
- `manifest.json` ও `sw.js` — PWA ইনস্টল এবং অফলাইন ক্যাশ
- `icon.svg`, `icon-192.png`, `icon-512.png` — লোগো/আইকন

## বিনামূল্যে অনলাইনে প্রকাশ (GitHub Pages)
1. GitHub-এ বিনামূল্যে অ্যাকাউন্ট খুলুন: https://github.com
2. নতুন Public repository তৈরি করুন, নাম দিন `kinioo7`.
3. এই ZIP-এর সব ফাইল repository-তে upload করুন (ফাইলগুলো root-এ থাকবে)।
4. Repository → Settings → Pages → Deploy from a branch → `main` এবং `/ (root)` নির্বাচন করে Save করুন।
5. প্রকাশিত `https://আপনার-ইউজারনেম.github.io/kinioo7/` ঠিকানাটি Android Chrome-এ খুলুন।
6. Chrome মেনু থেকে **Install app** অথবা **Add to Home screen** চাপুন।

PWA ইনস্টল করতে HTTPS দরকার; GitHub Pages বিনামূল্যে HTTPS দেয়। প্রথমবার অনলাইনে খুলুন; পরে ক্যাশ হওয়া ফাইল অফলাইনে খুলতে পারবে।

## নিজের affiliate link যোগ করবেন যেভাবে
`app.js`-এর `items` তালিকায় প্রতিটি পণ্যের `url:"#"` পরিবর্তন করে আপনার অনুমোদিত affiliate URL দিন। `title`, `desc`, `cat`, `emoji`, `tag` নিজের মতো সম্পাদনা করুন। `cat` হতে পারে: `bd`, `global`, `fashion`, `tech`, `stories`, `islamic`।

## গুরুত্বপূর্ণ সীমাবদ্ধতা ও আয়ের বাস্তবতা
- এটি কার্যকর প্রাথমিক ডিজাইন/প্রোটোটাইপ; এখনো কোনো বাস্তব পণ্য-ডেটাবেস, লগইন, পেমেন্ট, অর্ডার বা অ্যাড নেটওয়ার্ক যুক্ত নেই।
- Affiliate আয় পেতে সংশ্লিষ্ট প্রতিষ্ঠানের প্রোগ্রামে আবেদন করে অনুমোদন এবং নিয়মমাফিক affiliate link যোগ করতে হবে। সব প্রোগ্রাম বাংলাদেশি প্রকাশককে গ্রহণ করে না; দেশ ও ট্রাফিকের শর্ত যাচাই করুন।
- বিজ্ঞাপন আয় নিশ্চিত নয়; AdMob-এর মতো নেটওয়ার্কের অনুমোদন ও নীতিমালা মানতে হয়। এই PWA-তে AdMob স্বয়ংক্রিয়ভাবে কাজ করবে না; আলাদা সমন্বয়/Android wrapper বা উপযুক্ত web ad provider প্রয়োজন হতে পারে।
- অ্যাপ তৈরি/হোস্টিং বিনামূল্যে হলেও Google Play-এ প্রকাশের জন্য ডেভেলপার রেজিস্ট্রেশন ফি লাগতে পারে। তাই প্রথমে PWA হিসেবে বিনামূল্যে বিতরণ করুন।
- প্রকাশের আগে Privacy Policy, Contact, Affiliate Disclosure, Terms এবং কনটেন্টের উৎস যোগ করুন। অন্যের ছবি/লেখা অনুমতি ছাড়া ব্যবহার করবেন না।
- “Islamic” বিভাগে কুরআন-হাদিসের তথ্য প্রকাশের আগে নির্ভরযোগ্য সূত্র দিয়ে যাচাই করুন।

## পরবর্তী ধাপ
1. আপনার নিজের affiliate program-এ যোগ দিন।
2. নমুনা কার্ডগুলো বাস্তব পণ্য/কনটেন্ট দিয়ে প্রতিস্থাপন করুন।
3. Privacy Policy ও যোগাযোগের তথ্য যোগ করুন।
4. Facebook/YouTube থেকে দর্শক আনুন; ভুয়া ক্লিক বা নিজে নিজের affiliate link দিয়ে কেনাকাটা করে কমিশন নেওয়ার চেষ্টা করবেন না।
